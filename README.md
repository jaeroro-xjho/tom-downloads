# T.O.M.

T.O.M.(Task Operation Manager) Windows 설치 파일을 배포하는 공식 저장소입니다.

## 설치 방법

1. 오른쪽의 **Releases**에서 최신 버전을 엽니다.
2. `TOM-Setup-x.x.x.exe`를 다운로드합니다.
3. 설치 파일을 실행합니다.

앱을 설치한 뒤에는 별도의 GitHub 계정이나 인증키 없이 새 버전을 확인하고 업데이트할 수 있습니다.

## 데이터 보관

업무 데이터는 사용자의 PC에 저장됩니다. 업데이트 전이나 PC를 옮기기 전에는 T.O.M.의 **백업 내보내기**로 JSON 백업 파일을 보관해주세요.

## 저장소 구성

이 저장소에는 배포용 설치 파일과 공휴일 자료만 게시합니다. T.O.M. 애플리케이션의 개발 소스 코드는 포함하지 않습니다.
